One word for the boss: **Dementor**. The boss who walks in and sucks every last bit of joy out of the room — the word colleagues repeat at lunch because it lands. Short, vivid, fresh, and it works in a kitchen, a warehouse, or an office.

`main.ts` reads `entry.txt`, validates it (exactly one word, 1–30 characters, no whitespace, no control or invisible characters, must contain a letter), and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
